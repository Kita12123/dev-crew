## Getting Started
1. Install Dependencies
```
npm i
```
2. Generate Code
```
npm run generate
```

## Setup

1. Next.js
```
npm init -y
```

2. Prisma
```
npm install prisma --save-dev
npm install prisma/client@latest
```
